ZRA — Configuration
Configuration initiale

ZRA fait tourner un service en arrière-plan sur ce PC et le relance s'il s'arrête. Choisissez ce que ce PC doit faire, vérifiez les réglages réseau, puis enregistrez : l'icône ZRA apparaîtra dans la zone de notification, et tout se pilotera depuis son menu.

Runtime
Node.js
Exécutable Node ≥ 24 utilisé pour lancer le service. Le chemin absolu est figé à l'enregistrement.
détection…
Aucun exécutable Node ≥ 24 trouvé. Installer depuis nodejs.org, ou saisir un chemin valide.
Mode de service
Réseau
Port du daemon
Port sur lequel le service attend les connexions.Doit correspondre au port de zra.config.json.
Port d'écoute
Port sur lequel le service attend les connexions.
Hôte d'écoute
« Toutes les interfaces » (0.0.0.0) : joignable depuis le réseau.« Loopback seule » (127.0.0.1) : uniquement depuis cette machine — le cas d'un proxy HTTPS installé ici.« Adresse précise » : une seule interface, LAN ou VPN.
Adresse
IPv4 d'une interface de cette machine.
TLS
HTTP : le certificat est porté par le proxy placé devant ce serveur (Nginx Proxy Manager, Caddy…).HTTPS : ce serveur porte son propre certificat (Let's Encrypt, validation DNS-01).
Certificat
Fichier .crt — copié dans .zra/tls/.
Clé privée
Fichier .key — copié dans .zra/tls/.
