ZRA — Configuration
Configuration initiale

ZRA fait tourner un service en arrière-plan sur ce PC et le relance s'il s'arrête. Choisissez ce que ce PC doit faire, vérifiez les réglages réseau, puis enregistrez : l'icône ZRA apparaîtra dans la zone de notification, et tout se pilotera depuis son menu.

Runtime
Zed
L'éditeur dont ZRA pilote les agents. Détecté automatiquement.
détection…
Zed introuvable sur ce PC. Installer Zed (zed.dev) puis l'ouvrir une fois : ZRA branche ses agents à ce moment-là. Seule l'installation native est détectée — les versions Flatpak ou Snap ne sont pas prises en charge.
Node.js
Exécutable Node ≥ 24 utilisé pour lancer le service. Le chemin absolu est figé à l'enregistrement.
détection…
Aucun exécutable Node ≥ 24 trouvé. Installer depuis nodejs.org, ou saisir un chemin valide.
Mode de service
Réglages
Configuration
« Par défaut » convient à la plupart des postes. « Customiser » affiche tous les réglages.
Agents
Agents à piloter
Les agents qui passent par ZRA : leurs threads deviennent pilotables depuis le téléphone.
Démarrage
Lancer ZRA à l'ouverture de session
Le service démarre automatiquement à l'ouverture de votre session, sans élévation.
Forcer Zed sous XWayland
Nécessaire pour piloter Zed au clavier sous Wayland.
Sans XWayland, le pilotage au clavier ne fonctionne pas sous Wayland. Vous pourrez suivre les threads depuis le téléphone, mais pas ouvrir de session ni envoyer de commande à distance. Le rendu de Zed peut légèrement changer.
Réseau
Port du daemon
Port sur lequel le service attend les connexions.Doit correspondre au port de zra.config.json.
Port d'écoute
Port sur lequel le service attend les connexions.
Hôte d'écoute
« Toutes les interfaces » (0.0.0.0) : joignable depuis le réseau.« Loopback seule » (127.0.0.1) : uniquement depuis cette machine — le cas d'un proxy HTTPS installé ici.« Adresse précise » : une seule interface, LAN ou VPN.
Adresse
IPv4 d'une interface de cette machine.
TLS
HTTP : le certificat est porté par un proxy placé devant ce serveur (Nginx Proxy Manager, Caddy…).HTTPS : ce serveur porte son propre certificat (Let's Encrypt…).
Certificat
Fichier .crt — copié dans .zra/tls/.
Clé privée
Fichier .key — copié dans .zra/tls/.
Pare-feu
Tester l'écoute
Vérifie que le port peut être ouvert sur le réseau. Aucune règle de pare-feu n'est créée.
