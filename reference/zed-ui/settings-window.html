3. En-tête de fichiers

Sélecteur de portée : « User » toujours visible, puis le fichier courant et un menu « +N » pour les autres projets. Boutons Tinted Accent quand sélectionnés. À droite, « Edit in settings.json » (OutlinedGhost) ouvre le fichier dans l'éditeur.

9. Modale de confirmation

Composant ZedPromptRenderer (crates/ui_prompt), déclenché par Window::prompt(level, message, detail, answers). Scrim noir 20 %, dialogue centré 320 px (elevation_3), message + détail, pile de boutons pleine largeur. Écart ZRA : Zed ignore le niveau d'alerte ; ici la sévérité est visible — icône en tête et bouton d'action teinté (Accent / Warning / Error pour une suppression). Détails et clavier dans zed-ui.md.

Info — confirmation simple, action teintée Accent
Close this project?
Any unsaved changes will be lost.
Warning — icône warning, action teintée Warning
Trust this project?
Trusted projects can run tasks and load project settings.
Critical / suppression — icône error, bouton « Delete » rouge (Tinted Error)
Delete this skill?
This action cannot be undone.
Trois réponses — type pane.rs « Save / Don't Save / Cancel », actif = premier
Save changes before closing?
Your changes will be lost if you don't save them.

10. Modale de formulaire

Écart ZRA : Zed n'a pas de prompt formulaire — Window::prompt ne porte qu'un message et des réponses. ZRA compose ses primitives existantes : la surface elevation_3 et le scrim de ui_prompt, les champs SettingsInputField des settings, le Banner erreur, les boutons teintés. Dialogue centré 380 px (le prompt fait 320), tête icône + titre + fermer, champs pleine largeur avec libellé, action unique pleine largeur Tinted Accent. Pas d'« Annuler » : fermeture par la croix, Échap ou le backdrop ; Entrée valide. Détails dans zed-ui.md.
