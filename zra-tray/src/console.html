Installation
Installer sur ce poste
ZRA sera copié dans un emplacement fixe, avec un raccourci Menu Démarrer ; les chemins absolus (Zed, démarrage automatique) seront recâblés. Désinstallable proprement. Pas de retour arrière : la sortie est la désinstallation.
Désinstallation
Désinstaller ZRA
Arrête le service, retire le démarrage automatique, débranche Zed et supprime le dossier de l'application (code, journaux). La config (réglages, appairage, certificats) est conservée, sauf « tout désinstaller ». Node et Zed ne sont pas touchés.
Deux choix : tout désinstaller (plus aucune trace, config comprise), ou garder mes paramètres (config conservée dans votre dossier config, pour une réinstallation).
